# Request

Prepare the delivery of this repository: can we deliver what is on `main`?

The repository has a remote `origin`, its delivery branch is `origin/main`. There is no forge: the CI report of the commit is given to you in `ci.json`, beside the repository, in the format of `gh run list --json name,status,conclusion,headSha`.

Write your proposal in `out/proposal.json`, beside the repository and not inside it, in the skill's format, and return it with the skill's command. Nobody will give you a go-ahead during the session.
