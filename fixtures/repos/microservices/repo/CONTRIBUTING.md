# Contribuer

- Suivre PEP 8 ; lignes de 120 caractères au plus.
- Annoter les types des fonctions publiques et leur écrire une docstring.
- Garder les fonctions courtes et nommer clairement.
- Un test par comportement, pas par méthode.
- Une PR par sujet, avec une description.
- Les commits suivent Conventional Commits.
